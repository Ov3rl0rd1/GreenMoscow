# Озеленение города с учётом подземных коммуникаций — база знаний и исследование

Подготовительные материалы к задаче №3 Международного хакатона 2026:
**«Сервис для автоматического проектирования озеленения города с учётом расположения
подземных коммуникаций и городской среды»** (ДПиООС города Москвы).

**Дедлайн сдачи: 29.09.2026, 23:59 МСК.**

На текущем этапе это **исследовательская база**, а не код продукта: разбор ТЗ, нормативная
модель, обзор подходов и архитектур, машиночитаемые справочники и план работ.

## Ключевые выводы исследования

1. **Побеждает не веб-сервис, а пайплайн.** ТЗ трижды говорит, что UI второстепенен, а слабый
   алгоритм с отличным интерфейсом оценивается ниже точного пайплайна с CLI.

2. **Действуют две независимые системы ограничений.** Помимо таблицы 9.1 СП 42.13330.2016 есть
   охранные зоны (ПП РФ № 160, № 878, № 578, Приказ Минстроя № 197), которые часто строже.
   Именно оттуда берётся «не менее 2 метров от трубопроводов» из постановки задачи — из Правил
   охраны газораспределительных сетей, а не из СП, где стоит 1,5 м.

3. **ТЗ требует объяснять отказы, а не только посадки.** Самый пропускаемый пункт.
   Значит, нужен журнал всех рассмотренных кандидатов, а не только итоговых точек.

4. **Прочерк в таблице отступов — не ноль и не запрет.** Он означает «норма не установлена
   данной таблицей»; реальное ограничение может задавать охранная зона.

5. **Нейросеть предлагает — геометрия решает.** Нормативная часть детерминирована (только так
   решение прослеживается до строки НПА), ML применяется там, где есть реальная
   неопределённость: распознавание семантики грязных CAD-файлов и воспроизведение логики
   проектировщика при размещении.

6. **Файл заказчика `Шаблоны значков.dwg` вскрыт** (LibreDWG): 96 слоёв, 133 блока условных
   знаков с русскими названиями пород, единицы — метры, кодировка ANSI_1251. Обнаружена ловушка
   масштабов: блоки нарисованы в разных единицах, реальный размер = `bbox × INSERT.scale`.

## Важное ограничение текущей базы

Нормативные значения собраны из профессионального знания содержания документов, **но
официальные тексты не сверялись**: в окружении, где готовалась база, доступ к `docs.cntd.ru`,
`base.garant.ru`, `consultant.ru`, `pravo.gov.ru`, `mos.ru` был закрыт сетевой политикой.

Каждая цитата помечена статусом `verification`. Перед сдачей **обязательно** пройти
`docs/02-normative-verification-checklist.md` — это работа на 1–2 часа с обычным интернетом,
и от неё зависит ключевой критерий оценки («проверяемость обоснований»).

Правило до завершения сверки: **цитата со статусом `needs_check` не выводится в отчёт с номером
пункта** — формулировка даётся обобщённо.
