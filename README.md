Подготовительные материалы к задаче №3 Международного хакатона 2026:
**«Сервис для автоматического проектирования озеленения города с учётом расположения
подземных коммуникаций и городской среды»** (ДПиООС города Москвы).

**Дедлайн сдачи: 29.09.2026, 23:59 МСК.**

На текущем этапе это **исследовательская база**, а не код продукта: разбор ТЗ, нормативная
модель, сверенная по официальным текстам, разбор датасета, обзор подходов и архитектур,
машиночитаемые справочники и план работ.

## Ключевые выводы

1. **Побеждает не веб-сервис, а пайплайн.** ТЗ трижды говорит, что UI второстепенен.

2. **Две системы ограничений с разной юридической силой.** Таблица 9.1 СП 42.13330.2016
   (и московский дубль — табл. 3.6.1 743-ПП) даёт **запрет**; охранные зоны (ПП РФ № 160,
   № 878, № 578, Приказ Минстроя № 197) дают режим **«только с согласия эксплуатирующей
   организации»**. Отсюда три категории результата: недопустимо / условно / рекомендация.

3. **Отступ от сети меряется между наружными поверхностями трубы и ствола**
   (СП 42, прим. 5 к табл. 9.1), а не между осями. Диаметры труб есть в подписях тайлов.

4. **«Не менее 2 м от трубопроводов» из ТЗ** соответствует строке «теплопровод, трубопровод,
   теплосеть — 2,0» таблицы 3.6.1 743-ПП. Правила охраны газораспределительных сетей
   (ПП 878) прямого запрета посадки не содержат.

5. **ТЗ требует объяснять отказы, а не только посадки** — нужен журнал всех кандидатов.

6. **Датасет:** вход — xref-сборка главного чертежа из тайлов Мосгеотреста, где **тип сети
   закодирован именем слоя**; эталоны — планы посадок по принципу «порода = слой = блок»,
   тысячи точек с породой. Отдельных эталонов «без папок», как в ТЗ, нет.

7. **Нейросеть предлагает — геометрия решает.** Нормативная часть детерминирована, ML — для
   воспроизведения логики проектировщика (реальные данные для обучения есть) и для
   нестандартных подоснов.
